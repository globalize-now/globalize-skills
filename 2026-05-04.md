### `@lingui/cli` — the only behavioural change

1. **`dist/api/extractors/babel.d.ts`** — `getBabelParserOptions(...)` return type narrowed from a long inline union (`(ParserPluginWithOptions | "decimal" | "asyncDoExpressions" | …)[]`) to the named alias `ParserPlugin[]` from `@babel/parser`. The named alias resolves to the same set of values; this is a type-surface tidy with no runtime effect.

2. **`dist/lingui-extract.js`** — the `extract` Commander command gains one line:

   ```js
   .argument("[files...]", "Filter source paths to extract messages only from specific files")
   ```

   Net effect: `lingui extract` now accepts an **optional** trailing list of file paths. When omitted, behaviour is identical to 6.0.0 (full glob walk over the configured `catalogs[*].include` paths). When supplied, only the listed files contribute to the extraction pass — useful for IDE/lint integrations that want to re-extract a single file on save.

   The flag is **purely additive**. No existing CLI invocation pattern is altered, deprecated, or warned on.
