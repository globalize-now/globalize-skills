**`v6.6.0` changelog** ([compare v6.5.0…v6.6.0](https://github.com/lingui/js-lingui/compare/v6.5.0...v6.6.0)):

Features
- **`babel-plugin-lingui-macro`: nested `msg` and `t` support** ([#2625](https://github.com/lingui/js-lingui/issues/2625)) — the macros can now be nested inside one another (e.g. a `msg` placeholder that itself contains a `t`/`msg`).
- **`babel-plugin`: support Babel 8 via peer dependencies** ([#2623](https://github.com/lingui/js-lingui/issues/2623)) — Babel 8 (stable) is now an admitted peer alongside Babel 7.

Bug fixes
- `babel-plugin-lingui-macro`: unwrap non-null assertion (`x!`) and `satisfies` in placeholders ([#2622](https://github.com/lingui/js-lingui/issues/2622)).
- `cli`: preserve bracketed names in catalog globs ([#2621](https://github.com/lingui/js-lingui/issues/2621)).
- Improved error message for *"useLingui hook was used without I18nProvider"* ([#2624](https://github.com/lingui/js-lingui/issues/2624)).
- `react`: use `useSyncExternalStore` for the i18n provider ([#2612](https://github.com/lingui/js-lingui/issues/2612)).

**Compatibility (verified against the npm `package.json` for each version):**

- **`engines`:** `@lingui/core`, `@lingui/cli`, `@lingui/vite-plugin` all still `node >= 22.19.0` — byte-identical `6.5.0 → 6.6.0`. `@lingui/swc-plugin` has no `engines` (unchanged).
- **peers:** `@lingui/core` peer `babel-plugin-macros: '2 || 3'` unchanged. `@lingui/swc-plugin` peer `@lingui/core: '5 || 6'` and dep `@lingui/conf: '5 || 6'` unchanged. The one peer change is additive: **`@lingui/vite-plugin`'s `@babel/core` peer widened `^7.29.0 || ^8.0.0-rc.1` → `^7.29.0 || ^8.0.0`** — i.e. Babel 8 stable is now supported; Babel 7 projects are unaffected.
- **`^6` pins admit `6.6.0`.** No install-line or version-note change needed.

**`@lingui/swc-plugin` `6.5.1 → 6.6.0`:** the GitHub release page for the swc-plugin tag is empty (independent repo `lingui/swc-plugin` keeps no reliable Releases). The npm `package.json` is **byte-identical** between `6.5.1` and `6.6.0` — `engines` absent, peer `@lingui/core '5 || 6'`, dep `@lingui/conf '5 || 6'` all unchanged. No swc_core/ABI compat signal; the `6.6.0` bump reads as version alignment with the monorepo. Open item #3 (swc_core ABI re-verify) is unchanged by this.

**Actionability:** **not independently actionable.**
- The `^6` pins already admit `6.6.0`, so every emitted install continues to resolve; `engines` (Node `>=22.19.0`) is unchanged, so no Node-gate prose changes.
- **Babel 8 support needs no edit:** `grep` for `@babel/core` across `skills/` = **0 hits** — no skill pins `@babel/core`; the Babel-based paths (vite/react-babel, tanstack-start, react-router-framework, remix) only *reference* `@lingui/babel-plugin-lingui-macro` inside plugin config, and never assert a Babel major.
