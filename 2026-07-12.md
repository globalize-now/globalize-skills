TypeScript 7+ no longer provides the compiler API, so its `tsc` CLI is invoked in a child process instead; the emitted declarations are semantically equivalent but differ cosmetically between the two."*
- **`package.json`**: single addition — `devDependencies["typescript-go"]: "npm:typescript@7.0.2"` (a test fixture for the TS 7 path). Runtime `dependencies` **unchanged**. `peerDependencies` **unchanged** (`typescript >=5.6`, still optional via `peerDependenciesMeta`). No `engines` field, before or after.

**Verdict: not actionable.** No new config surface, no compat floor change. The skill installs `@inlang/paraglide-js@^2` (SvelteKit path: `paraglide/setup.add-ons.md`, `paraglide/json-format.setup.md`, `sveltekit/paraglide.setup.md`) and `^2` admits 2.21.0.
