## @lingui v6.0.0 — actionable

Breaking changes per the v6 announcement:

1. **ESM-only distribution.** Confirmed via npm metadata: `@lingui/core@6.0.0` and `@lingui/cli@6.0.0` ship `"type": "module"` and no CommonJS entry. Projects on CJS-only toolchains must migrate or stay on v5.
2. **Node.js minimum bumped to 22.19.0.** Confirmed via `engines.node` in v6 packages.
3. **`@lingui/macro` package removed.** Macros now live under per-package macro entrypoints (`@lingui/core/macro`, `@lingui/react/macro`) — which the skill's own examples already use. The package install lists are the only thing pointing at the deleted package.
4. Deprecated string format / `formatOptions` removed.
5. Deprecated TypeScript extractor removed.
6. Tightened TypeScript types (stricter nullability; clearer split between extracted-message and loaded-catalog shapes).
7. Install size dropped 62 MB → 35 MB; transitive deps 146 → 104.
8. `@lingui/swc-plugin@6.0.0` is dual-compatible: works against `@lingui/core@5` with `useLinguiV5IdGeneration: true`, and against `@lingui/core@6` natively (peer dep declared as `"5 || 6"`).

### Required edits in `skills/lingui/setup/`

**Drop `@lingui/macro` from every install command.** The package is gone in v6; installing it will error. References that need updating:

- `references/nextjs-app-router.md:18` — `npm install @lingui/core @lingui/react @lingui/macro`
- `references/nextjs-pages-router.md` — same install line (verify and fix)
- `references/tanstack-start-swc.md:23` — same
- `references/tanstack-start.md:19` — same
- `references/vite-swc.md` — same install line (verify and fix)
- `references/vite.md` (if present) — same
- `SKILL.md:178` — `@lingui/macro` row in the "Packages" table

The replacement on v6 is just `npm install @lingui/core @lingui/react` (runtime) and `npm install -D @lingui/cli @lingui/swc-plugin` (dev) — imports continue to come from `@lingui/react/macro` and `@lingui/core/macro`, which the skill's code samples already use correctly.

**Add a Node.js floor check to Step 1 detection.** If the project's Node version (or `engines.node`) is < 22.19, either pin `@lingui/*@^5` or warn before proceeding. Suggested wording: *"Lingui v6 requires Node.js 22.19+. Detected Node {x}. Either upgrade Node or install `@lingui/core@5 @lingui/react@5 @lingui/cli@5 @lingui/swc-plugin@5` instead."*

**Add an ESM/CJS gate.** If the project's `package.json` lacks `"type": "module"` and the build pipeline is CJS-only, surface this before installing v6.

**Update the SWC plugin version-pinning note.** `SKILL.md:751` currently says: *"`@lingui/swc-plugin` 5.10.1+ uses a stable Wasm ABI, so projects on Next.js 16.1+ or `@swc/core` >= 1.15.0 are unlikely to hit this."* — confirm this still holds for `@lingui/swc-plugin@6` (which is the new latest) and reword if the guidance is now: *"v6 of the swc-plugin uses the stable ABI; projects on Next 16.1+/swc_core 1.15+ should not need pinning."* Two existing example pin commands (`@5.8.0`, `@4.0.8`) stay correct as fallbacks for older Next.js / Vite-React-SWC versions.

**No code-sample changes.** Imports in `skills/lingui/setup/SKILL.md` (`@lingui/react/macro`, `@lingui/core/macro`) already match the v6 layout. `lingui-code` and `lingui-convert` were spot-checked and don't import from the removed `@lingui/macro` directly.

### Suggested rollout

Cleanest path is a single PR that:
1. Adds Node + ESM detection to Step 1.
2. Updates every install line + the package table to v6 syntax (drops `@lingui/macro`).
3. Adds a v5 fallback path (one paragraph) for projects that fail the Node/ESM gate.
4. Updates the swc-plugin gotcha section.
