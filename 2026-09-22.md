### Why it matters

Both Verification sections prove setup with `extract → compile → tsc → build`. None of those four can see a missing catalog. If `lingui compile` never ran, or a locale is in `decisions.md` but not in `lingui.config.ts`, the sequence passes and the site returns 500s. This is item 45 again ("a Verification section that gates only on exit codes cannot see…"), now in its **fourth** skill after #84's macro transform, #86's `_locales` bridge and the Lingui compile cases.

- The Verification sections get a catalog check: `.po` **and** `.ts` for every locale, in a subshell.
  - `.po` proves the locale is configured, because extract only writes configured locales.
