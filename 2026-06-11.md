### Lingui `6.3.0` (core suite, 2026-06-10)
From the upstream changelog (`v6.2.0...v6.3.0`):

- **Feature — `cli`: `BatchExtractor` support** (#2562). Internal extraction performance/API surface; the skills call `lingui extract` through the standard CLI, so no setup change is implied.
- **Fix — `po-format`: default `foldLength` now `0`** (#2567). Changes default line-wrapping of generated `.po` files (no folding by default). The skills don't set `foldLength`, so output changes cosmetically at most; nothing to edit. *Worth a one-line awareness note if the Lingui v6 setup rewrite (open item #2) ever documents PO formatter options.*
- **Fix — stop warning about `idPrefixLeader` in config** (#2561). Removes a spurious config warning; no skill action.

All in-range for the skills' `@lingui/*@^6` pins.

### `@lingui/swc-plugin` `6.4.0` (2026-06-10)
