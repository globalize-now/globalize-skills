## `next-intl` — release detail

Source: `https://github.com/amannn/next-intl/releases.atom`.

### 4.10.0 (2026-04-28 15:02 UTC) — Feature
- Add per-domain `localePrefix` override support ([#2273](https://github.com/amannn/next-intl/pull/2273))

When using domain-based routing, each domain entry in the `domains: [...]` array may now carry its own `localePrefix` value, overriding the top-level setting per domain.

### 4.10.1 (2026-04-28 16:07 UTC) — Bug Fix
- Set redirect domain if `x-forwarded-host` header exists ([#2281](https://github.com/amannn/next-intl/pull/2281))

Middleware-internal redirect behavior behind a reverse proxy. No public API change.

### 4.11.0 (2026-04-28 18:27 UTC) — Feature
- Add `displayName` to `useFormatter` ([#2285](https://github.com/amannn/next-intl/pull/2285))

The formatter returned from `useFormatter()` / `getFormatter()` gains a `displayName(code, options)` method, a thin wrapper around `Intl.DisplayNames` that picks up the active locale automatically. Useful for language pickers, region labels, currency names, etc.
